01 / Contexto

O problema de negócio

Em um negócio SaaS, entender quais clientes estão perdendo engajamento é importante para orientar ações de retenção. Mas antes de classificar risco, é necessário definir corretamente os clientes, as unidades, os pedidos e o significado de cada indicador.

O trabalho foi realizado para uma empresa real e envolveu organizar fontes operacionais, revisar as regras dos indicadores existentes e desenvolver uma aplicação multipágina que apresenta análises de negócio. A solução foi desenvolvida e entregue ao gestor como projeto profissional.

02 / A solução entregue

Aplicação analítica multipágina

Desenvolvimento de uma aplicação web para análise de clientes, comportamento, retenção e receita de uma empresa SaaS voltada ao setor de restaurantes. O trabalho foi entregue ao gestor e reúne estruturação em Python, interface Streamlit e consultas ao PostgreSQL.

O que o sistema contempla

Visão executiva, clientes em risco, Cliente 360, oportunidades de relacionamento, comercial, retenção preventiva, geografia da carteira, receita, cancelamentos históricos e inteligência de churn.
